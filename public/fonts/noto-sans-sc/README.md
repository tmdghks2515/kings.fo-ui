# Noto Sans SC

Self-hosted variable WOFF2 font from @fontsource-variable/noto-sans-sc 5.3.0 (Google Fonts v40).
Source: https://www.npmjs.com/package/@fontsource-variable/noto-sans-sc/v/5.3.0
Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
License: SIL Open Font License 1.1; see LICENSE.

index.css retains the upstream unicode-range subsets and weights 100-900.
The CSS family alias is Noto Sans SC; the font binaries are unchanged.
Only subsets needed for displayed characters are loaded by the browser.
